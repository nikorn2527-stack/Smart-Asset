# ข้อมูลหลักหน่วยงาน

เปิด **ตั้งค่า → ทะเบียนและหลักเกณฑ์ → ข้อมูลหลักหน่วยงาน** เพื่อเพิ่มข้อมูลที่ต้องใช้ซ้ำในงานรับเข้าและเบิกจ่าย

## ข้อมูลที่จัดการได้

| ประเภท | ใช้ในงาน | รายละเอียดเพิ่มเติม |
| --- | --- | --- |
| ผู้ขาย / ผู้ส่งมอบ | ใบรับเข้า และข้อมูลผู้ขายในทะเบียน | เลขผู้เสียภาษี ที่อยู่ โทรศัพท์ ผู้ติดต่อ |
| หน่วยงาน / แผนก | หน่วยงานปลายทางของใบเบิก / จัดสรร | หน่วยงานแม่ |
| คลัง / สถานที่ | จุดรับและเก็บของก่อนจัดสรร | สังกัด อาคาร ชั้น |
| บุคลากร | ผู้รับของ ผู้ขอ ผู้ตรวจรับ ผู้อนุมัติ ผู้จ่าย ผู้รับมอบ | สังกัด ตำแหน่ง โทรศัพท์ |
| หน่วยนับ | แต่ละแถวรับเข้า เช่น เครื่อง ชุด ตัว | หมายเหตุ |
| วิธีได้มา | รับซื้อ รับโอน รับบริจาค หรือวิธีที่หน่วยงานใช้ | หมายเหตุ / เงื่อนไข |
| แหล่งเงิน | เงินงบประมาณ เงินรายได้ เงินบริจาค หรือแหล่งเงินของหน่วยงาน | หมายเหตุ / เงื่อนไข |

**บัญชีหน่วยงานและสาขา หมวด ชนิด/คุณลักษณะ รูปแบบเลข และหลักเกณฑ์ค่าเสื่อม** ใช้หน้าตั้งหมวด เลขครุภัณฑ์ และค่าเสื่อมที่มีอยู่แล้ว ปุ่มด้านล่างหน้าข้อมูลหลักเปิดไปหน้าดังกล่าวได้ หน่วยงานเจ้าของบัญชีกับแผนกผู้ใช้งานเป็นคนละเรื่อง การจัดสรรให้แผนกไม่เปลี่ยนเจ้าของบัญชีหรือเลขครุภัณฑ์

รายชื่อบุคลากรเป็นข้อมูลผู้ปฏิบัติงาน ไม่ใช่บัญชีเข้าสู่ระบบ สิทธิ์ในต้นแบบยังใช้ตัวเลือกบทบาทจำลองเดิม

## เริ่มต้นและกำหนดขอบเขต

1. เลือกบัญชีหน่วยงาน เช่น โรงพยาบาลสุรินทร์ หรือศูนย์แพทย์ ตามเจ้าของข้อมูลจริง
2. เลือกประเภทข้อมูลและขอบเขตสาขา ข้อมูลระดับส่วนกลางใช้ได้ทั่วบัญชีนั้น ข้อมูลเฉพาะสาขาจะเลือกใช้ได้เฉพาะสาขานั้น
3. กด **เพิ่มข้อมูลหลัก** กรอกชื่อและรายละเอียด รหัสเว้นว่างให้ระบบออกให้ได้ รหัสนี้เป็นรหัสภายในสำหรับอ้างรายการ ไม่ใช่เลขครุภัณฑ์และไม่ใช่เลขแบบฟอร์มราชการ
4. ถ้าสร้างแผนก สถานที่ หรือบุคลากร สามารถเลือกหน่วยงานแม่/สังกัดจากข้อมูลแผนกในบัญชีเดียวกันได้ หน่วยงานแม่ต้องไม่วนกลับมาที่รายการเดิม
5. ค้นชื่อหรือรหัสเพื่อแก้ไข ถ้าเลิกใช้ให้ปิด **เปิดใช้งาน** แทนการลบ รายการที่ปิดยังค้นได้เมื่อเลือก **รวมที่ปิดใช้งาน** และเปิดใช้งานกลับได้

ชื่อที่ซ้ำในประเภทและขอบเขตเดียวกัน รวมถึงรหัสที่ซ้ำในประเภทเดียวกันของบัญชี จะถูกป้องกันไว้ แม้รายการเดิมจะปิดใช้งานแล้วก็ตาม ข้อมูลสาขาของรายการเดิมไม่ย้ายข้ามสาขา ให้สร้างรายการใหม่เมื่อเปลี่ยนขอบเขตการใช้งาน

## เลือกจากข้อมูลเดิม

ปุ่ม **เลือกจากข้อมูลเดิม** แสดงข้อความที่พบในทะเบียนหรือข้อมูลการได้มาของครุภัณฑ์ในบัญชีที่เลือก เช่น ผู้ขาย ชื่อแผนก สถานที่ ผู้ดูแล วิธีได้มา และแหล่งเงิน ส่วนหน่วยนับอ่านจากใบรับเข้าที่เคยบันทึก

ข้อความเหล่านี้เป็นข้อเสนอให้ตรวจสอบ กดชื่อเพื่อเปิดแบบเพิ่ม ตรวจชื่อ กรอกรหัสและรายละเอียด แล้วบันทึกเป็นข้อมูลหลักเอง ระบบไม่เดาหน่วยงานเจ้าของให้ข้อมูลที่ยังไม่แยกบัญชี และไม่เปลี่ยนทะเบียน/เอกสารต้นทางเพราะกดดูข้อเสนอ

กรณียังไม่มีข้อมูลเดิม ให้เริ่มจากรายการที่หน่วยงานใช้งานจริง ไม่ต้องสร้างรายการตัวอย่างเพื่อให้เลือก

## เลือกและเพิ่มจากหน้างาน

- ช่องผู้ขาย สถานที่ บุคลากร วิธีได้มา แหล่งเงิน และหน่วยนับในใบรับเข้า/เบิกจ่าย ค้นหาจากข้อมูลหลักของบัญชีและสาขาที่เลือกได้ พิมพ์ชื่อหรือรหัสแล้วเลือกรายการ ระบบส่งรหัสรายการไปบันทึก ไม่อาศัยข้อความแสดงผลเป็นตัวเชื่อม
- ปุ่ม **＋** ข้างช่องเปิดแบบเพิ่มข้อมูลหลัก เมื่อบันทึกจะเลือกรายการใหม่กลับให้ โดยไม่ล้างช่องอื่นของร่าง
- ถ้าพิมพ์ข้อความที่ไม่ตรงรายการใด ระบบยังรองรับการใช้ข้อความเฉพาะครั้งนั้น โดยแสดงคำว่า **ข้อความครั้งนี้** ชัดเจน ข้อมูลนี้จะไม่ถูกเพิ่มเข้าข้อมูลหลักอัตโนมัติ ถ้าต้องการใช้ซ้ำให้กด **＋** แล้วบันทึกก่อน
- เมื่อเลือกผู้ขาย ข้อมูลติดต่อที่เลือกจะติดไปกับเอกสารและข้อมูลการได้มาของครุภัณฑ์ด้วย

## เอกสารย้อนหลังและการแก้ข้อมูล

ใบงานเก็บรหัส ชื่อ รุ่นข้อมูล และรายละเอียดของข้อมูลหลัก ณ ตอนบันทึก การเปลี่ยนชื่อ ที่อยู่ หรือปิดใช้งานภายหลังไม่เปลี่ยนเอกสารที่ส่งดำเนินงานแล้ว หรือข้อมูลผู้ขายที่ขึ้นทะเบียนจากเอกสารนั้น

ถ้าข้อมูลหลักเปลี่ยนหลังบันทึกร่าง ก่อนกดส่งระบบจะให้กลับไป **แก้ไขร่าง** และเลือกข้อมูลล่าสุดแล้วบันทึกใหม่ หากรายการเดิมปิดใช้งาน ให้เลือกรายการที่เปิดใช้งาน หรือใช้ข้อความเฉพาะครั้งโดยชัดแจ้ง

ข้อมูลหลักและประวัติการแก้ไขเก็บใน SQLite และรวมอยู่ในชุดสำรองฐานข้อมูลเดิม ผู้ใช้ไม่ต้องย้ายไฟล์ข้อมูลหลักแยกต่างหาก
