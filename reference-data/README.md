# บัญชีตั้งต้นจากข้อมูลที่หน่วยงานให้มา

`classification-v1.json` สกัดจาก Excel 19 ไฟล์ใน `ครุภัณฑ์แยกประเภท.rar` ที่ผู้ใช้ส่งให้ โดยใช้หมวดจากไฟล์แยกประเภทและคอลัมน์ **ชนิดครุภัณฑ์** เป็นฐาน ไม่เดาความสัมพันธ์จากตัวอย่าง PDF

บัญชีนี้ประกอบด้วย:

- หมวดต้นทาง 19 หมวด
- คู่หมวด/ชื่อชนิด 1,195 รายการ รวมรายการที่ต้นทางไม่ระบุชื่อชนิดซึ่งแสดงแยกไว้
- คู่หมวด/รหัสจำแนก 3 ชุดแรก 1,918 รายการ (รหัสเดียวกันอาจพบหลายหมวด)
- ความสัมพันธ์หมวด–ชนิด–รหัส 3,276 รายการ
- ชนิดที่ยังไม่มีเลขครบรูปแบบ 3 รายการ เก็บชื่อไว้ให้ตรวจ ไม่สร้างเลขแทน
- ลำดับสูงสุดเดิมของเลขจำแนกแต่ละรหัส สำหรับต่อเลขชุดที่ 4 โดยไม่เริ่มซ้ำจาก 0001

ส่งออกเฉพาะหมวด ชื่อชนิด เลขจำแนก ชื่อไฟล์อ้างอิง และลำดับสูงสุด ไม่มีทะเบียนรายชิ้น ชื่อผู้ถือครอง ที่ตั้ง ราคาซื้อ เลขเครื่อง หรือข้อมูลติดต่อ ไม่ได้ทำให้ฐานสาธิตมีทรัพย์สินจริงเพิ่มขึ้น

หากรหัสเดียวมีชื่อชนิดหลายแบบในต้นทาง เก็บทุกความสัมพันธ์ไว้ให้เลือกตามชื่อและตรวจที่มา ไม่รวมชื่อหรือสร้างชื่อมาตรฐานใหม่ ช่องชื่อชนิดปรับเพียงช่องว่างซ้ำเพื่อไม่สร้างตัวเลือกซ้ำจากการเว้นวรรค

เมื่อเริ่มเซิร์ฟเวอร์ แอปติดตั้งบัญชีครั้งเดียวโดยใช้หมวดชื่อเดิมถ้ามีอยู่ รักษา ID, หมายเหตุ, สถานะปิดใช้งาน และการเชื่อมหลักเกณฑ์เดิม การเริ่มใหม่ไม่ล้างหรือเขียนทับข้อมูลที่เจ้าหน้าที่เพิ่มไว้ รหัสที่เจ้าหน้าที่กำหนดในบัญชีหน่วยงานยังใช้ร่วมกับบัญชีตั้งต้นได้

สร้างไฟล์ใหม่จากฐานนำเข้าที่ตรวจสอบแล้วด้วย Python มาตรฐาน (อ่านฐานแบบ read-only):

```powershell
py -3 scripts/build-classification-catalog.py --database "D:\Private\imported.sqlite3" --output "reference-data\classification-v1.json"
```

คำสั่งนี้สำหรับผู้ดูแลปรับชุดอ้างอิง ไม่ใช่ขั้นตอนที่ผู้ใช้ต้องทำหลัง `git pull` หากปรับชุดข้อมูลรุ่นถัดไป ต้องเพิ่ม migration ที่ตรวจทานการรวมกับข้อมูลหน่วยงาน ห้ามแก้ version เดิมแล้วหวังให้เขียนทับฐานที่ติดตั้งแล้ว

## ข้อความหลักเกณฑ์

`numbering-wording.json` คัดข้อความจากคู่มือ `คู่มือ การออกเลขครุภัณฑ์.pdf` หน้า PDF 2: ความหมายเลขทั้งสามชุด และย่อหน้าอธิบายการกำหนดเลขชุดที่สาม คงถ้อยคำต้นฉบับ โดยจัดการเว้นบรรทัดเพื่อแสดงบนเว็บ ข้อความนี้ไม่อ้างว่าคู่มือกำหนดเลขลำดับประจำชิ้นชุดที่สี่

เจ้าหน้าที่แก้ฉบับใช้งานในแอปได้ ข้อความที่แก้กับต้นฉบับเก็บแยกกันใน SQLite พร้อม revision และประวัติก่อน/หลัง การเริ่มเซิร์ฟเวอร์ใหม่ไม่เขียนทับข้อความที่แก้ไว้ ชื่อชนิดจาก Excel ใช้เป็นข้อมูลตั้งต้นของรหัสเท่านั้น ถ้าไม่มีเงื่อนไขในต้นทางจะไม่สร้างเงื่อนไขขึ้นเอง
